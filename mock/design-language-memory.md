# Design Language Memory

## Approved Direction
Use the retro editorial systems language we froze for `pulkitverma.xyz`: print-like structure, technical clarity, and a confident builder aesthetic. It should feel like a magazine layout meets a working notebook, not a playful retro theme or a generic personal site.

## Visual Tokens
- Backgrounds: warm paper tones, off-white layers, subtle gradients, and lightly textured contrast.
- Typography: expressive serif for headlines, mono for labels/meta, clean sans for supporting copy.
- Layout: strong grid, clear hierarchy, generous whitespace around primary actions, compact trust rails.
- UI feel: boxed cards, visible borders, restrained shadows, editorial spacing, and purposeful external-link signaling.

## UX Principles
- Make the first screen answer three things fast: who Pulkit is, what he does, and where to click next.
- Keep the hero clean and legible; the primary CTA should never feel crowded.
- Treat `Technical Notes` as a real publishing surface, not filler content.
- Keep the right rail compact and trustworthy, not like a second hero section.
- Use consistent link language and clear destinations for anchors, internal pages, and external proof links.

## LinkedIn Outreach Rule
LinkedIn outreach should reuse this same language, tone, and visual direction. That means the outreach should sound sharp, editorial, and technically credible, with the same sense of restraint and confidence as the site.

## Do / Don’t
Do:
- Keep messages concise, opinionated, and specific.
- Reuse the same vocabulary: deterministic systems, agentic workflows, technical notes, product clarity.
- Match the site’s calm confidence and founder-builder energy.

Don’t:
- Drift into generic networking language or overly salesy copy.
- Introduce flashy retro gimmicks, neon-heavy styling, or playful clutter.
- Break the visual system with mismatched fonts, colors, or link behavior.
